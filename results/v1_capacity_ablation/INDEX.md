# v1 学习表征容量消融 — 原始日志与结论

硬件 RTX 4060 Laptop 8GB / torch 2.11.0+cu128。除注明外均为
`--epochs 20 --fit-n 12000 --device cuda`，数据划分固定种子（`random.Random(0)`），
模型种子固定（`torch.manual_seed(0)`），故运行间差异仅来自 GPU 核非确定性。

v0 基线（确定性，fit-n 12000）：整体 0.802 / phishing 0.634 / ponzi 0.583 /
sandwich 0.758 / rug_pull 0.935 / flash_loan 0.993 / price 0.995 / D_open 0.929。

## 1. 主结论：v1 无增益，且对超参不敏感

26 次运行、8 个单轴配置，跨 64 倍参数量与 5.3 倍上下文长度：

- 整体 AUROC 全部落在 **0.795–0.806**（v0 = 0.802）
- ponzi 全部落在 **0.535–0.555**（v0 = 0.583）
- phishing 全部落在 **0.646–0.657**（v0 = 0.634）

GPU_HANDOFF 的判读标准为「弱信号类型（phishing/ponzi/sandwich）提升 ≥ 0.03」。
phishing 稳定 +0.017、ponzi 稳定 −0.04、sandwich ≈ 0，**无一类达标**。

该结论的强度在于超参不敏感性：v1 无增益不是调参不足所致。

## 3. 组合配置的交互效应（机制未明）

`block_size=256 d_model=128 n_layer=4 max_graphs=8000 epochs=30`：

| 运行 | 代码路径 | 整体 | ponzi | D_open |
|---|---|---|---|---|
| unblocked r1 / r2 | 硬编码 | 0.770 / 0.770 | 0.404 / 0.418 | 0.904 / 0.907 |
| combo r1 / r2 | CLI 参数 | 0.770 / 0.770 | 0.407 / 0.393 | 0.902 / 0.904 |

**五个轴单独变指标全部不动，五个一起变则稳定崩塌**，四次独立运行、两套代码路径一致。
留一法仅完成 `no-bs`（block_size 退回 48，其余不变）：整体 0.774 / 0.773、
ponzi 0.403 / 0.399，**仍崩塌**，故 block_size 不参与该交互。其余四轴的组合成因未定位。

本项作为观察到的事实记录，**不做因果归因**。

## 4. ponzi 秩反转

组合配置下 ponzi AUROC 四次全部 < 0.5（0.404 / 0.418 / 0.407 / 0.393），
即模型给 ponzi 交易的困惑度**排名**系统性低于正常交易。

注意表述边界：本框架的每格校准是纯秩变换（`mlusd/calibrate/ecdf.py`
`q = searchsorted(ref, v)/(n+1)`），校准后已不保留似然幅度信息。故此处能主张的是
**秩反转**，而非"深度生成模型给 OOD 更高似然"式的幅度陈述。

秩变换与 AUROC 可交换，故单格判别力不受校准层影响——「v1 无增益」的归因不因校准而混淆。
（最终分是 IsolationForest 跑在 8 维分位向量上，多元聚合对逐维单调变换并不严格不变，
故"v1 的幅度优势未被多元聚合利用"这一较弱的替代解释尚未排除。）

## 5. 样本量限制

分类型测试样本 n≈20（D_open n=22），单个样本约值 0.05 AUROC。上述所有分类型数字的
抽样置信区间宽于运行间波动，分类型比较应配合自助置信区间解读。

## 复现

```bash
python -m experiments.exp_v1_train --epochs 20 --fit-n 12000 --device cuda \
  --d-model 128 --block-size 256 --n-layer 4 --max-graphs 8000 --tag combo
```

不带容量参数时使用默认 48/64/2/800，等价于本目录 `exp_v1_train_full.log` 的配置。
