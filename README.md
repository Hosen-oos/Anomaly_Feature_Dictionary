# Anomaly Feature Dictionary (mlusd)
### 面向区块链广义异常交易的多层统一信号检测

> 一笔交易进入系统 → 提取 **4 层 × 3 范式**异常签名矩阵 → 按"信息可用性"分组校准 →
> **双通道**判定（已知类型字典匹配 / 未知类型开放识别）→ 输出判定 + 结构化解释。

一个**统一框架**：无需 per-type 训练即可检测多种异常类型，具备开放集检测、可扩展、
per-group 误报保证与结构化可解释性。面向**广义异常交易**（不限于 DeFi）。

---

## 核心结果（真实以太坊数据）

**最终配置显著性检验**（全增强数据 + 双路表示；配对自助，CI 不含 0 记为显著；
见 `experiments/exp_dual_repr_verify.py`）：

| 目标 | 本框架 | IForest | Δ [95%CI] | 判定 |
|---|---|---|---|---|
| **整体六类** | **0.876** | 0.807 | **+0.069 [+0.04,+0.09]** | ✅ **显著胜** |
| **D_open 真未知** | **0.963** | 0.707 | **+0.256 [+0.16,+0.35]** | ✅ 显著胜 |
| **phishing** | 0.678 | 0.467 | **+0.210 [+0.14,+0.27]** | ✅ 显著胜 |
| **ponzi** | 0.764 | 0.570 | **+0.194 [+0.17,+0.22]** | ✅ 显著胜 |
| sandwich | 0.932 | 0.914 | +0.019 [−0.01,+0.05] | ⚪ 打平 |
| flash_loan / price_manip | 0.991 / 1.000 | 0.996 / 1.000 | ≈0 | ⚪ 打平 |
| **rug_pull** | 0.946 | 0.982 | −0.036 [−0.06,−0.01] | ❌ 显著负 |

- **已知类型检测显著优于最强基线**（+0.069）；**真未知检测大幅领先**（+0.256）。
- **仅 rug_pull 一项显著落后**（−0.036）——已诊断清楚（`exp_rugpull_diag.py`）：
  ① 其签名是**极端原始计数**（转账 76 vs 正常 0.75，z=70；日志 105 vs 1.57）；
  ② **秩校准在极端尾部饱和**——76/200/1000 的分位数都≈0.999，量级差异被压掉，
  而 IForest 用原始计数可区分。这是分位数方法的**固有代价**（换来跨类型可比与分布无关稳健性）；
  ③ 字典机理错配：`liquidity_exit` 基于 `remove_liquidity`，但本数据集 rug_pull
  **全为砸盘型（0/20 含 Burn 事件）**而非撤 LP 型，该参数恒为 0 是死参数；
  ④ 尝试补 log 量级通道**无效**（+0.008，噪声内，且其他类型各降一点，整体持平，故未采纳）。
- **适用边界**：优势依赖多层数据完整性。在缺失 L3/邻域的配置 B（RPC 采集）下，
  整体显著落后（−0.138），真未知优势不再显著（+0.008 [−0.11,+0.11]）。
  紧凑表示的代价是脆弱：本框架 8 格死 2 格（25%），IForest 25 维只死 4 维（16%）。

**双路表示（关键设计，`dual_repr=True` 为默认）**：开放集检测同时消费
**8 维格值**与 **47 维参数分位数**两种表示，取全局分位数的 max。

| 目标 | 单路(8维格值) | 双路 | Δ |
|---|---|---|---|
| 整体 | 0.839 | **0.876** | +0.037 |
| **sandwich** | 0.776 | **0.932** | **+0.156** |
| D_open | 0.927 | 0.963 | +0.036 |
| phishing | 0.697 | 0.678 | −0.019（CI 重叠） |

> **设计洞察**：格内 max 聚合等价于**隐式特征选择**——对信号**集中**的类型有益
> （phishing 集中在 L2-j3 单格），对信号**关系型/分散**的类型有害（sandwich 的同池反向
> 等证据散落多参数，被更极端参数掩盖）。双路取 max 使两者兼得，与格内参数池的
> 非稀释 max 是**同一母题**，只是上升一个层次。这说明**聚合粒度本身应是可配置维度**。

- **基线不具备的能力**：per-group FP 保证（各组误报 ≈ α=1%）/ 结构化可解释 / 类型归因 / 免重训扩展。
- **消融**：学习聚合 +0.092、校准 +0.050 为主要贡献；量值化与分组校准在当前数据上
  为噪声级（±0.002）。消融结论依赖数据丰富度——退化配置下学习聚合的收益消失。

### 增量改进（在基础配置 0.786 之上逐项累加）

| 改进 | 检测 AUROC | 主要受益 |
|---|---|---|
| 基础（学习聚合 + 量值化） | 0.786 | — |
| + 锚定美元利润 | 0.794 | phishing +0.017 |
| + 跨交易上下文（同区块结构） | 0.818 | sandwich +0.017 |
| **+ L4 广义化（合约结构性信号）** | **0.836** | **ponzi +0.140** |

- **可解释性**：贡献度 top-1 命中攻击机理层级 **0.67**，随机期望 0.39（**+71%**）；
  与检测能力自洽（sandwich/price/flash 0.90–1.00，ponzi 为负——检测也最差）。
- **效率**：单笔 35.5 ms（28 笔/秒）。M2 信号提取 64.6% + M5 开放识别 34.3%，
  **M3 校准 + M4 匹配 + M6 决策合计仅 1.1%** → 框架核心机制近乎零开销；
  采集（RPC 0.43 s/笔）比检测慢 12 倍，瓶颈在数据获取。
- **机理发现（不泄漏）**：攻击交互的合约中位部署 **0 天**（临时部署攻击合约），
  phishing 针对 **730 天**老牌合法代币，正常 330 天。
- **双通道各司其职**：`opposite_same_pool` 在 sandwich 命中 82.5% vs 正常 1.7%（48 倍富集），
  但在**类型无关**的开放集检测里仅 +0.014（被稀释），在**类型特异**的字典归因里
  使 sandwich 达 **10/10**。同一信号两通道价值悬殊 → 双通道互补而非冗余。

### 类型归因（per-param 对比式字典）

| 配置 | 准确率 |
|---|---|
| 原基线（手写先验 + 聚合格值） | 25% |
| + per-param 参数粒度 | 39% |
| + 对比式权重（k vs 其他攻击） | 45% |
| **+ 利润归因特征** | **62%** |
| + 强三明治判定（文献共识条件） | 61%（sandwich **10/10**、ponzi 10/10） |
| 合并 flash_loan + price_manipulation（标注歧义检验） | **75%** |

- **per-param 对比式字典**：权重学"类型 k vs 其他攻击"而非"vs 正常"（各攻击相对正常的偏离
  方向雷同，只有类间对比才有判别力），负权重即否定证据；掩码感知（层不可用不产出证据）。
  把 ponzi/rug_pull 从"永不被预测的死类"救活（0→8、0→5）。
- **利润归因**（`signals/profit.py`）：(地址×代币) 资金流台账 → 10 个与代币小数位无关的比值
  特征（passthrough / drain_imbalance / profit&loss_concentration / victim_is_pool …），
  phishing 归因 0→7。
- **标注歧义发现**：flash_loan 与 price_manipulation 经三次独立尝试均无法分离，但**合并两类后
  准确率 +13 点** → 模型能识别"闪电贷驱动的经济攻击"家族，分不清的是家族内标签划分
  （DeFiHackLabs/DefiLlama 按主要技术归类，而闪电贷驱动的预言机操控同时满足两类定义）。
- **事件解码覆盖**：新增 UniV3 Flash / Balancer / Maker / AaveV1 / ERC3156 闪电贷、Compound
  借贷、dYdX、UniV2 Sync 等签名 → flashloan 动作识别 **20%→75%**，总解码覆盖率 64%。

## 架构（六模块流水线）

```
tx → M1 采集 → M2 四层×三范式信号矩阵 S + 可用性掩码 m
   → M3 分组 ECDF 校准（共形 p 值）+ 尾部放大
   → { M4 已知类型字典匹配(权重+FP阈值) ; M5 未知开放识别(学习聚合+组内再校准) }
   → M6 优先级判定 + 贡献度解释 → DetectionReport
```

- **四层**：L1 交易图拓扑 / L2 合约交互语义 / L3 EVM 执行轨迹 / L4 链下情报
- **三范式**：分布偏离 / 经济异常 / 信息差异
- **核心主张**：异构可用性——不同异常的信息落在不同层，掩码 + 分组校准如实承接缺层

### GPU 实验（v1 学习表征）

> 换到 GPU 机器请看 **[GPU_HANDOFF.md](GPU_HANDOFF.md)**——自包含的交接指南
> （环境、数据准备、实验目标与判读标准、已踩过的坑）。

```bash
pip install -e ".[learn]"
python -m experiments.exp_v1_train --epochs 20 --fit-n 12000 --device cuda
```

v1 把三个格子换成学习模型（L1-j1 图自编码器 / L2-j1 动作序列 Transformer /
L3-j1 调用树 LM，BlockGPT 缩小版），其余 5 格保持 v0 规则版；脚本输出 v0-vs-v1 的
整体、分类型与 D_open 真未知 AUROC 对比。三个模型均支持 `device="auto"` 自动用 CUDA。

#### 结论：v1 学习表征无增益（负面结果，证据充分）

原始日志见 `results/v1_capacity_ablation/`（45 份）与其 `INDEX.md`。

- **单轴容量消融**：`d_model` ∈ {32,64,128,256}、`block_size` ∈ {48,96,192,256}、
  `n_layer`、`max_graphs`、`epochs` 各单独变动，**26 次运行的整体 AUROC 全部落在
  0.795–0.806**（v0 = 0.802），ponzi 全部 0.535–0.554，phishing 全部 0.646–0.657。
  跨 **64 倍参数量**与 **5.3 倍上下文长度**指标几乎不动。
- 判读标准（见 GPU_HANDOFF §3）为"弱信号类型提升 ≥0.03"，**无一类达标**。
- **组合配置**（五轴同时放大）稳定崩塌至 0.770、ponzi 0.39–0.42（四次复现、两套代码路径），
  但**五个轴单独变动均无退化**——记录为观察到的交互效应，机制未明，不做因果归因。

**为何不敏感——结构性解释（`exp_rank_invariance.py`）**：ECDF 校准为单调秩变换
`q = rank(v)/(n+1)`，而 AUROC 为秩指标，故对任一信号位 **AUROC(原始) ≡ AUROC(校准)**。
容量主要改变困惑度的**尺度与锐度**，不改变**排序**，因而无法穿过校准层。

> 这同时澄清了一个潜在质疑：校准层**不可能**抹掉学习表征的判别力——若 v1 的格子更有
> 判别力，AUROC 会如实反映。故"v1 无增益"的归因是干净的，不存在"被秩校准抵消"这一
> 替代解释。**秩变换丢弃的是幅度**，这与 rug_pull 的极端量级签名被压缩是**同一性质的
> 两种表现**：秩校准既是稳健性来源（对提取器实现细节与分布形态不敏感、跨类型可比），
> 也是固有局限（幅度信息不进入决策）。

## 数据集

⚠️ **采集管线一致性**：BigQuery 采集含 trace（100%），Alchemy 免费档 RPC 无 trace（0%）。
单凭"是否有 trace"即可完美分离两者（AUROC=1.000），故**跨管线比较会被污染**。
评测须在同管线内进行，为此提供两套内部一致的配置。

| 数据集 | 规模 | 采集 | 说明 |
|---|---|---|---|
| `d_cal` / `d_cal_nbr` | 24000 | BigQuery | 正常校准集（_nbr 含邻域图增强） |
| `d_known` / `d_known_nbr` | 111 | BigQuery | 六类攻击（各 ~20） |
| `d_open` | 22 | BigQuery | 真未知（重入/访问控制/业务逻辑，字典中无） |
| `d_cal_rpc` | 5987 | RPC | 管线对齐的正常集（无 trace） |
| `d_known_rpc` | 199 | RPC | 攻击集，经济类补齐（flash 48/rug 45/ponzi 42/price 24） |
| `d_open_rpc` | 19 | RPC | 真未知，管线对齐 |
| `d_phish_ptx` / `d_benign_ptx` | 4986 / 13067 | RPC | PTXPHISH（NDSS'25）钓鱼 + 硬负样本 |
| `d_known_ext` | 800 | BigQuery | phishing + sandwich 各 400 |

**两套评测配置**（各自内部一致，不可跨配置比较）：
- **A 全特征**：`d_cal_nbr` + `d_known_nbr` + `d_open`（有 L3 + 邻域图）
- **B 管线对齐**：`d_cal_rpc` + `d_known_rpc` + `d_open_rpc`（无 L3/邻域，攻击样本 1.8x）

配置 B 上本框架已知类型显著落后 IForest（0.699 vs 0.837，Δ=−0.138 显著），且真未知
优势消失（+0.008 不显著）——**框架优势依赖多层数据完整性**，这是适用边界，应如实报告。
